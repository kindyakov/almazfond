# 404 Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a branded 404 page with a home link and a dedicated CTA that opens the existing help modal with 404-specific copy.

**Architecture:** Keep the 404 page inside the existing static page pipeline by adding a new file under `src/pages`. Reuse the existing modal infrastructure and extend variant resolution with one focused `not-found` option instead of creating a second modal or special-case JavaScript path.

**Tech Stack:** HTML partial includes, project CSS sections, vanilla JavaScript module, Node `node:test`

---

- [ ] **Step 2: Run test to verify it fails**

- [ ] **Step 3: Write minimal implementation**

